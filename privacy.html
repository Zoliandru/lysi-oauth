Politique de confidentialité — Lysi

Version 2026-09-16 · App Lysi · Éditeur légal Lysi Hub

Site : zoliandru.github.io/lysi-oauth

Contact : lysihub@icloud.com — voir aussi Support.

En bref

Lysi est une application locale d’abord. Vos notes restent sur votre iPhone (et, si vous l’activez, dans votre propre iCloud via les mécanismes Apple). Lysi ne vend pas vos données, n’affiche pas de publicité et n’utilise pas de traqueurs publicitaires.

1. Qui est responsable

Produit : Lysi (display) · Cadre éditeur : Lysi Hub

Contact confidentialité / support : lysihub@icloud.com

2. Données que Lysi traite

2.1 Contenu que vous créez (notes)

  • Texte saisi, dicté ou importé (Share Extension, Lysi Drop, etc.).
  • Stockage : sur l’appareil (SwiftData), dans le bac à sable de l’app / App Group associé.
  • Lysi n’envoie pas le contenu de vos notes vers un serveur Lysi : il n’y en a pas pour l’inbox.

2.2 Destinations que vous choisissez

Lorsque vous envoyez une note vers une app ou un service que vous avez configuré, le contenu nécessaire est transmis uniquement à cette destination, par exemple :

DestinationMécanisme typique
Rappels / Calendrier AppleAPIs système (EventKit), sur votre appareil / compte Apple
MessagesComposeur système prérempli
Notion, GitHub, GitLabAPI officielles avec jeton que vous connectez
Due, Drafts, Obsidian, Things, Raccourci…Ouverture via URL / app tierce
WebhookPOST HTTPS vers l’URL que vous avez saisie
Partage / Copier / FichierSheet système, presse-papiers, Fichiers iOS

Les politiques de ces tiers s’appliquent dès que les données les rejoignent. Lysi ne contrôle pas Notion, GitHub, etc.

2.3 Identifiants de connexion (secrets)

  • Jetons OAuth, clés API, PAT : stockés dans le Keychain iOS, pas dans les préférences en clair.
  • Vous pouvez les effacer depuis Réglages → Confidentialité.

2.4 Préférences

  • Réglages non sensibles (mode capture, confirmation Siri, actions configurées, etc.) : stockage local (App Group / UserDefaults selon le cas).

2.5 Permissions système (Just-in-Time)

Lysi demande l’accès au moment de l’usage, jamais toutes les permissions au lancement :

PermissionUsage
Microphone / reconnaissance vocaleDictée → texte
RappelsCréer des rappels depuis une note
CalendriersCréer un événement brouillon
ContactsChoisir un destinataire Messages (numéro mémorisé sur l’action)
BadgeAfficher le nombre de notes en attente (si activé)
Fichiers / importChoisir un dossier (ex. Lysi Drop) ou importer un preset

2.6 Diagnostics

Si Apple ou le système fournit des rapports de crash / diagnostics, ils peuvent contenir des données techniques non destinées à reconstruire le contenu de vos notes. Lysi n’intègre pas de SDK publicitaire ni d’analytics tiers au moment de ce document.

3. Ce que Lysi ne fait pas

  • Pas de compte Lysi obligatoire
  • Pas de publicité
  • Pas de vente de données
  • Pas de tracking cross-app à des fins publicitaires
  • Pas d’envoi automatique de vos notes vers un cloud Lysi

4. Conservation

  • Notes et archives : tant que vous ne les supprimez pas (rétention archives configurable dans l’app).
  • Secrets Keychain : jusqu’à effacement manuel ou désinstallation (comportement Keychain iOS).
  • Aucune durée de rétention serveur Lysi : pas de serveur de contenu.

5. Vos droits

Selon votre situation (dont RGPD si applicable) : accès, rectification, effacement — principalement en gérant le contenu dans l’app et en effaçant les identifiants. Pour toute demande : lysihub@icloud.com · page Support.

6. Enfants

Lysi n’est pas destinée aux enfants de moins de 13 ans. Catégorie App Store prévue : 4+ (pas de contenu problématique) ; pas de collecte ciblée d’enfants.

7. Modifications

Toute mise à jour matérielle de cette politique sera indiquée par date en tête de page. L’usage continu après publication vaut prise de connaissance.
